CSS Grids

Grids are very useful, especially when you want to align your content differently depending on the size of the screen!

You can change how many grid columns and rows there are, or even how many columns or rows different pieces of information take up!

CSS Positioning

You can see, the top navigation is stuck at the top of the screen when you scroll! This is due to positioning!

Positioning is helpful for many things, especially in determining different elements relations to each other in the browser.

CSS Flexbox

Flexbox can give a similar vibe to grid if you only want essentially one row of columns! You've been seeing this in action the whole time!

The navigation buttons are all side by side using flex in css!

Responsive CSS

Not all screens are built equal, so one version of a browser isn't going to look right in every single one! This is where Responsive CSS comes in!

Using @media, we can tell our code, "Hey! When the screen is this big, layout the items like this!" Depending on your device, the @media function is being used right now!
